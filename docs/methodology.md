## 策略构造

我先按因子值对同一时点的币种排序，分别建立多头和空头仓位。每个因子独立计算，最后等权组合。

## 研究区间

| 区间 | 日期 | 用途 |
|---|---|---|
| 样本内 | 2022-01-01 至 2024-09-01 | 因子参数训练与研究 |
| 样本外 | 2024-09-01 至 2025-09-22 | 训练后表现评估 |

分界日 2024-09-01 归入样本外：样本内取该日之前的数据，样本外从该日开始并包含 2025-09-22。组合按同一账户连续回测，分界日延续持仓，绩效按区间分别统计。

单因子页面保留历史参数实验，组合页面使用上表的区间计算结果。

## 绩效计算

每日收益为当日盈亏除以固定本金。计算绩效时，先把小时收益加总为每日收益。

| 指标 | 定义 |
|---|---|
| 累计收益 | 每日收益相加 |
| 算术年化收益 | 日收益均值乘以 365 |
| 夏普比率 | 日收益均值除以样本标准差，再乘以 365 的平方根；无风险利率为零 |
| 最大回撤 | 累计收益距历史高点的最大差值，以固定本金计量 |
| 收益回撤比 | 算术年化收益除以最大回撤 |

回撤采用固定本金口径。程序将回撤保留三位小数后计算收益回撤比。各区间的回撤分别根据该区间收益计算，整体曲线保持连续。

## 组合与费用

初始本金为 100,000，交易费率参数为 0.00025。各因子的交易费用与资金费率分别计入收益，再按 1/9 权重合成组合。仓位也按相同权重合成。

实盘账户在运行期间的吃单费率为 0.0005、挂单费率为 0.0002，平均成交费率约为 0.00038。回测结果保留原有的 0.00025 费率假设，执行成本的比较见[交易成本与执行研究](execution.md)。

这段实盘每次调仓均以固定的 2,000 USDT 作为组合总资金，再按目标仓位换算下单数量，与回测的固定本金单利计算方式一致。账户截图与历史回测分别记录，实盘结果见[运行记录](live-trading.md)。
